# N&M Travel Website — Version 1

This is a low-cost static website prototype for N&M Travel.

## Included
- Myanmar / English / Chinese language switch
- China / Thailand Visa service sections
- Requirements section
- Online application form
- Demo application IDs such as VISA-2026-0001
- Demo queue numbers such as CN-001 / TH-001
- Application status lookup
- Admin dashboard demo
- N&M Travel logo

## Important
Version 1 uses browser localStorage for demonstration only. It is NOT suitable for real customer documents or production operations yet.

## Production upgrade
The next step is to connect:
1. Cloudflare Pages — website hosting
2. Supabase — secure database + document storage
3. Staff login / permissions
4. Real queue counter shared by all customers
5. Real application status
6. AI Assistant using N&M Travel's approved knowledge base
7. Optional Telegram / Messenger / WhatsApp notifications

Target running cost: approximately $5–10/month initially, depending on domain and AI usage.
